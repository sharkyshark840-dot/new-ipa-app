# Project brief

**Status:** Prototype defined

## Product

- **Audience:** Adults (18+).
- **Primary development computer:** Windows.
- **iPhone build route:** GitHub repository connected to Codemagic's macOS builder.
- **Distribution goal:** Personal-device testing with a signed IPA.

## Included prototype sessions

1. **Follow the dot:** a brief on-screen moving-dot exercise.
2. **See far away:** a large-symbol, user-paced practice flow intended for a chosen distance.

## Non-goals

- No diagnosis, medical screening result, lazy-eye detection claim, prescription measurement, or treatment recommendation.
- No camera recording, microphone recording, data upload, user account, or cloud storage.

See `SAFETY_SCOPE.md` for the rules that apply to all future work.
